A small program that writes one short text (103 characters) to `/output/entry.txt`: a hilariously useless superpower — the narrator can read minds, but only their own, and only after they have already said the embarrassing thing out loud.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
